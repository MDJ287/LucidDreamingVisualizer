# LucidDreamingVisualizer
Outer Wilds mod for testing Lucid Dreaming setups

## default keybinds:
* `[G]`: toggle camera display to view the direction you will go toward the dream world
* `[P]`: enable dream world
* `[O]`: disable cloaking field zero-g, so you should land exactly where you would if you went and slept and waited for the stranger to start moving (and it should take exactly the same amount of time)
* `[,]`/`[,]`: move camera away from / towards the sun
* `[']`: hold to multiply `[,]`/`[.]` movements by 10x

NOTE: when you enable the dream world it will not render all the terrain, you have to get relatively close to it. you should be able to get close enough from within the cloaking field
